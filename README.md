# 和文手書きフォント・作字スタジオ (Japanese Handwriting Font Studio)

ブラウザ上でひらがな・カタカナ・英数字・JIS水準漢字（第一水準〜第三水準・教育漢字）の手書きおよびベクター作字を行い、TrueType（`.ttf`）、OpenType（`.otf`）、Webフォント（`.woff`）、ベクター（`.svg`）、iOS/iPadOS構成プロファイル（`.mobileconfig`）として出力できる本格的なWebフォント開発スタジオです。

PC（マウス・液晶ペンタブレット）、タブレット（iPad / Apple Pencil）、スマートフォン（タッチ操作）に完全対応し、PWA（Progressive Web App）およびService Workerによるオフライン高速動作に対応しています。GitHub Pages等の静的ホスティングで簡単に公開・運用が可能です。

---

## 🌟 主な機能一覧

### 1. ⚡ PWA & オフライン動作対応
- **Service Worker (Workbox)**: 静的アセット、Google Fonts、WebManifestをブラウザに自動プリキャッシュし、ネットワーク接続がない環境でも全機能が動作。
- **PWA インストール対応**: デスクトップ（Chrome, Edge）およびモバイル（Android / iOS Safari）でのアプリ追加（「ホーム画面に追加」）をサポート。
- **オフライン接続表示**: ネットワーク状態の変化をリアルタイムで検知し、オフライン動作インジケーターを表示。

### 2. 💾 堅牢な二重化オートセーブ & ストレージ管理
- **二重化自動保存 (IndexedDB + LocalStorage)**: 2000msデバウンスにより、キャンバス上の描画・編集操作をバックグラウンドで安全に連続保存。
- **スナップショット世代管理**: IndexedDB内に最新15世代のローリングバックアップを自動保持し、誤操作やブラウザ閉鎖時からの即時復元が可能。
- **即時手動バックアップ & インポート**: プロジェクト全体（`.fontproj.json`）の書き出し/読み込み、および単一グリフのJSON形式での即時バックアップに対応。

### 3. 🎨 手書き・ベクター描画 & iPad / ペンタブレット最適化
- **Apple Pencil / スタイラス筆圧感知 (Pressure Sensitivity)**:
  - iPadOS / WebKitのハードウェア筆圧センサー（0.04〜0.70）を全域フルレンジ（0〜100%）に最適校正。
  - リアルタイム筆圧感知バッジ（画面上で「筆圧: ○○%」を即時確認可能）。
  - 筆圧感度設定（高 / 標準 / 低 / OFF）およびベジェ曲線による滑らかな筆圧ダイナミクスカーブ。
- **超軽快レスポンス & 120fps（ProMotion）適応プレビュー**:
  - 描画中のイベント合流（`getCoalescedEvents`）と軽量リアルタイムプレビューにより、iPad Pro / Air等の高リフレッシュレート画面でも一切の遅延なくペン先に追従。
  - ストローク終了時（筆上げ時）にのみ三次ベジェ曲線フィッティング（Cubic Bézier）と高品質輪郭生成を実行。
- **多画数でも重くならない局所サブセットブーリアン結合 (Localized Subset Union)**:
  - 画数が増えても文字全体の全輪郭を再計算せず、重なり合う周囲の輪郭のみを局所的に高速マージ。
  - 弱参照（WeakMap）キャッシュにより、既存パスのSVG文字列生成負荷をほぼゼロ化。
- **18種類の多彩なブラシスタイル**:
  - 毛筆、万年筆、ミリペン、平筆カリグラフィー、和風墨筆、漫画Gペン、ファミコン風ドット筆、カクカク角筆、角丸筆、手書き風ゆらぎ筆、チョーク等
- **iPadタッチジェスチャー & パームリジェクション**:
  - **2本指タップ**: 直前の操作を取り消し (Undo)
  - **3本指タップ**: やり直し (Redo)
  - **2本指ピンチ / スワイプ**: キャンバスの拡大・縮小・パン移動
  - **パームリジェクション（手のひら誤タッチ防止）**: 自動判定 / スタイラス専用モード切替に対応。
- **ベジェペン & ダイレクトノード編集**: アンカーポイント・制御点の移動、角丸・スムーズ切替、複数ノードの一括整列・削除。
- **輪郭結合 (Union) & 単純化 (Simplify)**: 重なり合った描画ストロークの一括パス結合、および過剰ノードの幾何学的削減。

### 4. 📐 和文作図キャンバス & 全10種類作図基準ガイド
- **仮想ボディと字面枠**: 1000 UPM基準。漢字字面枠（90%）・仮名字面枠（80%）の表示切り替え。
- **作図基準ガイド（全10種類）**:
  - 十文字格（十字線）、米字格（八方位線）、九宮格（三分割線）、田字格（四等分）、回字格（二重枠）、同心円格、黄金比ガイド、3×3ブロック、六角グリッド、欧文4線ガイド
- **凡例カード & カスタムガイド線**: 定規からのドラッグ配置による水平・垂直ガイド線（スナップ対応）。
- **隣接文字表示 & グリフ重ね合わせ比較**: 前後文字の透過表示、および他グリフとの半透明重ね合わせ比較。

### 5. 🛠️ 作字支援ツール & 自動生成機能
- **複数ウェイト自動補間**: 2マスター間の幾何補間による全5ウェイト（Thin / Light / Regular / Bold / Heavy）ファミリーの一括生成（ZIP出力）。
- **部首スタジオ & 康熙部首パレット**: 偏（へん）・旁（つくり）・冠（かんむり）等、康熙214部首の高品質ベクターデータ抽出と自由配置・合成。
- **自動濁点・半濁点・小書き仮名生成**: 清音データから濁点・半濁点（「が」「ぱ」等）や小書き仮名（「っ」「ゃ」等）を自動配置・一括生成。
- **下絵・画像トレース & SVGインポート**: 外部画像（ノート手書き写真や下絵）の自動輪郭抽出（Marching Squares + Bézier fitting）およびSVGパス読み込み。

### 6. 🔤 組版・フォント仕様対応
- **縦書きOpenType対応 (`GSUB vert`)**: 縦書き表示用の句読点、長音符、括弧、小書き仮名の置換テーブルを自動構築。
- **ペアカーニング (`GPOS kern`)**: 特定文字ペア間の文字送り・余白調整。
- **自動字幅・余白バランス調整 (Auto-Spacing)**: バウンディングボックスと視覚的重心をもとに左右余白（LSB / RSB）を自動最適化。
- **フォント品質チェック (Quality Checker)**: 自己交差、極値ノード欠落、過剰ノードの自動診断と補正。
- **リアルタイムテスト組版プレビュー**: 縦書き・横書き文庫風リアルタイム組版シミュレーション。

## 💻 開発・ビルド & GitHub Pages デプロイ

### 1. ローカル開発環境

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (ポート 3000)
npm run dev

# 型チェック (TypeScript Linter)
npm run lint

# 静的ビルド (dist/ ディレクトリに出力)
npm run build
```

### 2. GitHub Pages への公開手順

本リポジトリには `.github/workflows/deploy.yml` が含まれており、`main` または `master` ブランチへプッシュするだけで自動的に GitHub Pages へビルド＆デプロイされます。

1. GitHub リポジトリの **Settings** > **Pages** に移動します。
2. **Build and deployment** の Source で **GitHub Actions** を選択します。
3. `git push origin main` を実行すると、自動ビルドが開始し、数分でサイトが公開されます。
