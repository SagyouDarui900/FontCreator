# FontCreator
ブラウザ上でひらがな・カタカナ・英数字・漢字を手書き＆ベクター作字し、日本語フォント（TrueType `.ttf` / OpenType `.otf`）として書き出せるオープンソースのWebアプリケーションです。

インストール不要でブラウザ完結。PC（マウス・ペンタブレット）、iPad（Apple Pencil）、スマートフォン（タッチ操作）のいずれでもに作字・フォント出力できます。

---

## 主な特徴

### 1. 和文タイポグラフィに特化した作図キャンバス
- **仮想ボディと字面枠**: 1000 UPM（フォント標準単位）の仮想ボディに対し、漢字字面枠（90%）・仮名字面枠（80%）を標準装備。
- **多彩な作図ガイド**: 十文字・米字・九宮格・欧文ベースライン・キャップハイト・ディセンダー表示。
- **カスタムガイド線**: キャンバス上部の定規からドラッグして引ける水平・垂直ガイド線（吸着スナップ対応）。
- **隣接文字の薄字表示**: 前後の文字を左右に透かし表示しながら作字でき、文字列としての並びや字間をその場で確認可能。

### 2. 本格的な手書き＆ベクター描画エンジン
- **筆圧感知（Stylus API）**: Apple Pencil、Wacom、Surface Penの筆圧にダイレクト連動。
- **豊富なペン・ブラシスタイル**: 毛筆（楷書・行書）、丸ペン、ミリペン、カリグラフィ平筆、サインペンなど。
- **手振れ補正 & スムージング**: 描画線のぶれを抑え、TrueType規格に最適な滑らかな二次ベジェ曲線へ自動変換。
- **ベジェ曲線ペン & ノード編集**: Illustratorライクなアンカーポイント操作、方向線の調整、角丸化・スムーズ切替。
- **交差輪郭自動結合（Union）**: 重なったストロークをTrueTypeのNon-Zeroワインディング規則に適合する中空結合輪郭へ一括統合。

### 3. 和文フォント制作を加速する支援スタジオ
- **自動濁点・半濁点生成**: 「か」から「が」、「は」から「ば・ぱ」へ、濁点位置を自動計算して複製・配置。
- **小書き仮名の自動変形**: 「つ」から「っ」、「や」から「ゃ」など、80%縮小・右下寄り配置へワンクリック変換。
- **部首スタジオ**: 偏（へん）・旁（つくり）・冠（かんむり）・脚（あし）などの部首パーツを組み合わせて複雑な漢字を制作。
- **グリフ合成スタジオ**: 制作済みの文字をパーツとして合成（例:「木」＋「木」＝「林」）。
- **下絵・写真トレース**: 手書きノートや原稿用紙の写真を背景に読み込んで透かしトレース。
- **SVGパーツ取り込み**: Illustrator等で制作したSVGベクターパスをドラッグ＆ドロップで直接取り込み。

### 4. 高度な組版・フォント仕様対応
- **縦書きOpenType対応 (`GSUB vert`)**: 縦書き表示時に句読点（、。）や長音符（ー）、括弧（「」）、小書き仮名を自動的に縦書き位置へ回転・置換するGSUBテーブルを自動生成。
- **ペアカーニング (`GPOS kern`)**: 「ト」と「―」、「っ」と後続文字など、文字同士の食い込みや余白バランスを視覚的に調整可能。
- **スマート自動調律**: バウンディングボックスと視覚的重心を解析し、左右余白（LSB / RSB）と字幅を自動バランシング。
- **フォント品質チェッカー**: 輪郭の自己交差、極値ノード欠落、過剰ノードを自動検出しワンクリック修正。

### 5. 多彩なエクスポート＆利用環境
- **TrueType (`.ttf`) / OpenType (`.otf`)**: Windows / macOS / Linux / iOS / Androidでそのまま使える標準フォントファイルを出力。
- **iPadワンタップインストール**: iOS/iPadOSの構成プロファイル形式 (`.mobileconfig`) を自動生成し、設定アプリから即座にiPadにフォントをインストール可能。
- **プロジェクトセーブデータ (`.fontproj.json`)**: 制作途中データを安全にJSONバックアップ。他端末との共有や共同作業にも対応。
- **商用利用完全自由**: 本ツールで作成したフォントは、同人誌、YouTube動画テロップ、ゲーム、商業印刷物、Webフォントなど用途を問わず自由にご利用いただけます。

## キーボードショートカット一覧

（※アプリ内でいつでも `?` キーを押すことで画面上にも一覧が表示されます）

### ツール切替
| キー | 機能 |
| :--- | :--- |
| <kbd>B</kbd> | 筆・毛筆ブラシツール |
| <kbd>P</kbd> | ベクターペンツール（ベジェ曲線） |
| <kbd>V</kbd> | 選択・移動ツール |
| <kbd>A</kbd> | ノード編集・ダイレクト選択ツール |
| <kbd>E</kbd> | 消しゴムツール |
| <kbd>U</kbd> / <kbd>S</kbd> | 長方形ツール |
| <kbd>O</kbd> | 楕円・円ツール |
| <kbd>R</kbd> | 定規・距離計測ツール |
| <kbd>H</kbd> | 手のひらツール（キャンバスパン移動） |

### 描画・ブラシ調整
| キー | 機能 |
| :--- | :--- |
| <kbd>[</kbd> / <kbd>]</kbd> | ブラシ / 消しゴムの太さを細く / 太く (-2px / +2px) |
| <kbd>Shift</kbd> + <kbd>[</kbd> / <kbd>]</kbd> | ブラシ太さを 10px 単位で大幅変更 |
| <kbd>Shift</kbd> + ドラッグ | 水平・垂直・45度の正確な直線ストロークを描画 |
| <kbd>Enter</kbd> | ペンツールでのパス描画を確定・輪郭を閉じる |
| <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>Z</kbd> | ペン描画中に直前に置いたノードを1つ取り消す |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 選択中のパス、または選択中のノードを削除 |
| <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>A</kbd> | 現在の文字の全パスを選択 |
| <kbd>Alt</kbd> + <kbd>S</kbd> | パスの単純化（頂点を削減して滑らかに） |
| <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd> | スマート自動字幅・左右余白バランス調整 |

### 表示・キャンバス操作
| キー | 機能 |
| :--- | :--- |
| <kbd>Space</kbd> + ドラッグ | 一時的に手のひらツール（キャンバスをパン移動） |
| <kbd>0</kbd> | キャンバス全体を画面に最適フィット (Fit to Screen) |
| <kbd>1</kbd> | 等倍表示 (100%) |

| <kbd>F</kbd> / <kbd>Shift</kbd> + <kbd>Z</kbd> | 全面作図・集中モード (サイドバー収納/展開) |
| <kbd>\</kbd> | 文字一覧サイドバーの開閉 |
| <kbd>G</kbd> | 方眼グリッドの表示 / 非表示 |
| <kbd>Alt</kbd> + <kbd>+</kbd> / <kbd>-</kbd> | 方眼グリッドのマス目サイズを微調整 |

### 文字送り・ナビゲーション
| キー | 機能 |
| :--- | :--- |
| <kbd>Alt</kbd> + <kbd>→</kbd> / <kbd>PageDown</kbd> | 次の文字へ進む（五十音順・漢字順） |

## 🛠️ 開発・ビルド環境

### 前提条件
- Node.js 18.0 以上
- npm 9.0 以上

### インストールと起動

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (ポート 3000)
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

### プロダクションビルド

```bash
# 静的アセットのビルド (dist/ ディレクトリに出力)
npm run build
```

## 📂 プロジェクト構成

```text
src/
├── components/          # UIコンポーネント群
│   ├── canvas/          # キャンバス構成レイヤー (背景, ガイド, 隣接文字, ルーラー等)
│   ├── GlyphCanvas.tsx  # メイン作図キャンバス (ベジェ, 筆圧, タッチ)
│   ├── GlyphGrid.tsx    # 文字一覧マトリクス (五十音, JIS第1水準, 常用漢字等)
│   ├── Header.tsx       # トップバー (出力, 保存, 各種スタジオ導線)
│   ├── ToolBar.tsx      # 左側ツールパレット (ペン, 筆, 消しゴム, 図形)
│   ├── MetricsPanel.tsx # 右側メトリクス・変形パネル (字幅, 余白, 回転, 反転)
│   ├── TestPreviewModal.tsx  # 縦書き・横書きリアルタイム組版テスト
│   ├── ShortcutsHelpModal.tsx # キーボードショートカット集モーダル
│   └── ...
├── data/
│   └── unicodeTables.ts # ひらがな・カタカナ・漢字・記号のUnicode定義テーブル
├── utils/
│   ├── fontCompiler.ts  # TrueType / OpenType バイナリコンパイラ
│   ├── pathUtils.ts     # ベクター幾何計算, 筆圧ストローク, 交差結合
│   ├── metricsHelper.ts # 字幅・余白自動バランサー

├── types.ts             # 型定義 (FontProject, GlyphData, PathContour等)
└── App.tsx              # メインワークスペース統合コンポーネント
```
