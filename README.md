# 和文手書きフォント・作字スタジオ (Japanese Handwriting Font Studio)

ブラウザ上でひらがな・カタカナ・英文字・記号・JIS水準漢字（第一水準〜第三水準・教育漢字）の手書きおよびベクター作字を行い、TrueType（`.ttf`）、OpenType（`.otf`）、Webフォント（`.woff` / `.woff2`）、ベクター（`.svg`）、iOS/iPadOS構成プロファイル（`.mobileconfig`）形式で直接出力できるWebフォント作成ツールです。

PC（マウス・液晶ペンタブレット）、タブレット（iPad / Apple Pencil）、スマートフォン（タッチ操作）に対応し、PWA（Progressive Web App）およびService Workerによる完全オフラインでの動作に対応しています。GitHub Pagesなどの静的ホスティング環境でも公開・運用が可能です。

---

## 主な機能

### 1. PWA・オフライン・レスポンシブ対応
- **Service Worker (Workbox)**: 静的アセット、Google Fonts、WebManifestをブラウザにキャッシュし、オフライン環境でも動作します。
- **PWAインストール**: デスクトップ（Chrome, Edge）およびモバイル（Android / iOS Safari）でのホーム画面へのアプリインストールに対応しています。
- **接続状態の表示**: ネットワーク接続の状態を検知し、オフライン時にはインジケーターを表示します。
- **マルチデバイス対応**: iPad・タブレットの120Hz高リフレッシュレート表示、スタイラスペン、スマートフォンのタッチ・ピンチジェスチャーに対応しています。

### 2. 自動保存・ストレージ・データ管理
- **自動保存 (IndexedDB / LocalStorage)**: 編集内容を定期的に自動保存し、ブラウザを閉じても作業状態を保持します。
- **履歴・スナップショット管理**: IndexedDB内にローリングバックアップを保持し、過去の状態への復元が可能です。
- **プロジェクトのインポート・エクスポート**: プロジェクト全体（`.fontproj.json`）の書き出し・読み込み、および単一グリフのJSON形式での保存・読み込みに対応しています。

### 3. 手書き・ベクター描画機能
- **高解像度スプライン描画 & 120Hz描画更新**:
  * 描画イベントを1.5pxステップのCatmull-Rom連続スプラインで計算し、60fpsおよび120fps環境での描画更新に対応しています。
  * 描画中の仮線と確定後の輪郭に同一の塗りルール（`fillRule="nonzero"`）を適用し、確定時および再描画時の表示の差異を防ぎます。
- **重なり白抜きの自動解消**:
  * 交差線（「十」「木」など）やループ線（「の」「す」など）の交差部が白く抜けないよう、独立ストロークを `fillRule="nonzero"` で描画し、文字の内側の閉領域（「口」「日」など）を自動判定して穴として処理します。
- **筆圧感知・Apple Pencil対応**:
  * Apple Pencilおよびスタイラスペンの筆圧感知に対応しています。
  * キャンバス上での筆圧数値表示、筆圧感度の設定（高 / 標準 / 低 / OFF）、筆圧カーブの調整が可能です。
- **ペンスタジオ & マイブラシ登録機能**:
  * 毛筆、万年筆、ミリペン、平筆、和風墨筆、Gペン、ドット筆、角筆、角丸筆、チョーク、鉛筆、マーカーなどのプリセットを搭載しています。
  * 筆圧カーブ、入り抜き（テーパー）、ペン先角度・扁平率、ジッター（揺らぎ）、速度変化（Speed Width）の各パラメーターを調整できます。
  * 調整したブラシ設定を「マイブラシ」として保存し、JSON形式での書き出し・読み込みが可能です。
  * パラメーター入力値の自動クランプおよびゼロ除算保護処理を備えています。
- **手ブレ補正 & 歪み補正**:
  * 手ブレ補正強度（強 / 標準 / 弱）を選択可能。入力座標の平滑化により、手の震えによる線のブレを抑制します。
  * 描画後に線のうねりを直線化する補正機能を搭載しています。
- **ジェスチャー操作・パームリジェクション**:
  * 2本指タップでの取り消し (Undo)、3本指タップでのやり直し (Redo)、ピンチ・スワイプによる拡大・縮小・パン移動に対応しています。
  * 手のひらの接触による誤操作を防ぐパームリジェクション機能およびペン専用モード（`auto` / `strict_pen_only` / `off`）を備えています。
- **ベジェペン・ノード編集**:
  * アンカーポイントや制御点の移動、角丸・スムーズ切り替え、複数ノードの整列・削除が可能です。
- **輪郭結合・単純化 (Simplify)**:
  * 重なり合ったストロークのパス結合、および不要なノードの自動削減（形状を保持したパス単純化）が可能です。
- **ピクセルフォント作成スタジオ**:
  * ドット絵・ビットマップ形式での作字およびグリフ変換に対応しています。

### 4. 作図キャンバス・ガイド機能
- **テーマカラー連動**:
  * ライト・ダーク・セピア・ウォーム・Nord・モノクロームの各テーマに対応。選択したテーマに応じて文字色とグリッド背景色が切り替わります。
- **仮想ボディと字面枠**:
  * 1000 UPMを基準とし、漢字字面枠（85%）・仮名字面枠 (78%) の表示切り替えが可能です。
- **作図基準ガイド**:
  * 田字格、十文字格、米字格、九宮格、回字格、同心円格、黄金比ガイド、3×3ブロック、六角グリッド、欧文4線ガイドを表示できます。
- **カスタムガイド線**: 定規からのドラッグによる水平・垂直ガイド線の配置（スナップ対応）およびキーボード操作でのロック切り替えが可能です。
- **前後文字・下絵・他グリフの透過表示**:
  * 前後の文字や指定したグリフを半透明で重ねて比較表示できます。
  * 下絵画像からの輪郭抽出（トレース）および位置・拡大率（78% / 85% / 100% プリセット）調整が可能です。

### 5. 作字支援機能
- **ウェイト補間**: 2つのマスターデータ間の幾何補間により、複数ウェイト（Thin / Light / Regular / Bold / Heavy）を一括生成できます。
- **部首パレット**: 康熙部首等のパーツを抽出し、偏（へん）・旁（つくり）・冠（かんむり）などを組み合わせて作字できます。
- **濁点・半濁点・小書き仮名の自動配置**: 清音データから濁点・半濁点や小書き仮名を生成できます。
- **画像トレース・SVGインポート**: 手書き画像からの輪郭抽出（トレース）およびSVGパスの読み込みに対応しています。

### 6. 組版・フォント出力仕様
- **出力フォーマット**:
  * TrueType (`.ttf`)、OpenType (`.otf`)、Webフォント (`.woff` / `.woff2`)、ベクター (`.svg`)、iOS/iPadOS構成プロファイル (`.mobileconfig`)。
- **縦書きOpenType機能 (`GSUB vert`)**: 縦書き表示用の句読点、長音符、括弧、小書き仮名の置換テーブルを出力します。
- **ペアカーニング (`GPOS kern`)**: 文字ペアごとの字間調整に対応しています。
- **自動字幅・余白調整**: バウンディングボックスと視覚的重心に基づき、左右余白（LSB / RSB）を調整できます。
- **品質チェック**: 自己交差や過剰ノードの検知と自動補正を行えます。
- **組版プレビュー**: 縦書き・横書きでのテスト組版プレビューが可能です。

## 主なキーボードショートカット

アプリ内で `?` キーを押すことで、ショートカット一覧および使い方のガイドを確認できます。

### ツール切り替え
| キー | 機能 |
| :--- | :--- |
| `B` | ブラシツール |
| `P` | ベクターペンツール（ベジェ曲線） |
| `V` | 選択・移動ツール |
| `A` | ノード編集・ダイレクト選択ツール |
| `E` | 消しゴムツール |
| `U` / `S` | 長方形ツール |
| `O` | 楕円・円ツール |
| `R` | 定規・距離計測ツール |
| `H` | 手のひらツール（キャンバス移動） |

### 描画・ブラシ調整
| キー | 機能 |
| :--- | :--- |
| `[` / `]` | ブラシ・消しゴムサイズ変更 (-2px / +2px) |
| `Shift` + `[` / `]` | ブラシサイズ変更 (10px単位) |
| `Shift` + ドラッグ | 水平・垂直・45度の直線描画 |
| `Enter` | パス描画の確定・輪郭を閉じる |
| `Ctrl` / `Cmd` + `Z` | 取り消し (Undo) |
| `Ctrl` / `Cmd` + `Shift` + `Z` | やり直し (Redo) |
| `Delete` / `Backspace` | 選択中のパス・ノードを削除 |
| `Ctrl` / `Cmd` + `A` | すべてのパスを選択 |
| `Alt` + `S` | パスの単純化 (Simplify) |
| `Shift` + `Alt` + `S` | 自動字幅・余白バランス調整 |

### 表示・キャンバス操作
| キー | 機能 |
| :--- | :--- |
| `Space` + ドラッグ | 手のひらツール（パン移動） |
| `0` | 全体表示（画面に合わせる） |
| `1` | 等倍表示 (100%) |
| `W` | 幅に合わせる |
| `+` / `-` | ズームイン / ズームアウト |
| `F` / `Shift` + `Z` | 全面作図モード切り替え |
| `\` | 文字一覧サイドバーの開閉 |
| `G` | 方眼グリッドの表示切り替え |

### 保存・プロジェクト管理
| キー | 機能 |
| :--- | :--- |
| `Ctrl` / `Cmd` + `S` | プロジェクトの保存 |
| `Esc` | 描画キャンセル / 選択解除 / モーダルを閉じる |
| `?` | ヘルプ・ショートカット一覧を表示 |

## 開発・ビルド・デプロイ

### 1. ローカル開発環境

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (ポート 3000)
npm run dev

# 型チェック
npm run lint

# プロダクションビルド (dist/ ディレクトリに出力)
npm run build
```

### 2. GitHub Pages への公開手順

本リポジトリには `.github/workflows/deploy.yml` が設定されており、`main` または `master` ブランチへプッシュすることで GitHub Pages へ自動デプロイされます。

1. GitHub リポジトリの **Settings** > **Pages** を開きます。
2. **Build and deployment** の Source で **GitHub Actions** を選択します。
3. `main` ブランチへプッシュすると、GitHub Actions が実行され、サイトが公開されます。
