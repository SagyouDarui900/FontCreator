# FontCerator

ブラウザ上でひらがな・カタカナ・英数字・漢字の手書きおよびベクター作字を行い、TrueType（`.ttf`）やOpenType（`.otf`）フォントとして出力できるWebアプリケーションです。

PC（マウス・ペンタブレット）、タブレット（Apple Pencil等）、スマートフォン（タッチ操作）に対応しています。

---

## 機能一覧

### 1. 和文作図キャンバス
- **仮想ボディと字面枠**: 1000 UPM基準。漢字字面枠（90%）・仮名字面枠（80%）の表示切り替え。
- **作図ガイド**: 十文字、米字、九宮格、欧文ベースライン、キャップハイト、ディセンダー。
- **カスタムガイド線**: 定規からのドラッグによる水平・垂直ガイド線配置（スナップ対応）。
- **隣接文字表示**: 前後の文字を左右に半透明表示し、字間や並びを確認しながら編集可能。
- **グリフ重ね合わせ比較**: 別の文字をキャンバス上に半透明で重ね合わせ、骨格やバランスを比較。

### 2. 手書き・ベクター描画
- **筆圧感知（Stylus API）**: スタイラスペンの筆圧に応じた線幅変化に対応。
- **ペン・ブラシプリセット**: 毛筆、丸ペン、ミリペン、平筆、サインペン等。
- **手振れ補正 & スムージング**: 入力曲線を二次ベジェ曲線に変換。
- **ベジェペン & ノード編集**: アンカーポイント・制御点の移動、角丸・スムーズ切り替え。
- **輪郭結合（Union）**: 重なったストロークをTrueType規格に準拠した結合輪郭に変換。

### 3. 作字支援ツール
- **複数ウェイト自動補間**: 輪郭の一括オフセット（太さ増減）および2マスター間の幾何補間によるファミリー展開（ZIP一括出力）。
- **自動濁点・半濁点生成**: 清音のグリフデータから濁点・半濁点付きグリフを自動配置・生成。
- **小書き仮名変換**: 対象の仮名を縮小・位置調整して小書き文字（「っ」「ゃ」等）を生成。
- **部首スタジオ & グリフ合成**: 偏（へん）・旁（つくり）などの部首や既存グリフを組み合わせて合成。
- **下絵・画像トレース**: 外部画像（下絵や原稿用紙）を背景に読み込んで透過表示。
- **SVGインポート**: ベクターパスのドラッグ＆ドロップ読み込み。

### 4. 組版・フォント仕様対応
- **縦書きOpenType対応 (`GSUB vert`)**: 縦書き表示用の句読点、長音符、括弧、小書き仮名のグリフ置換テーブルを生成。
- **ペアカーニング (`GPOS kern`)**: 指定した文字ペア間の余白・送り幅を調整。
- **字幅・余白調整**: バウンディングボックスと視覚的重心をもとに左右余白（LSB / RSB）を自動調整。
- **フォント品質チェック**: 輪郭の自己交差、極値ノード欠落、過剰ノードの検出と修正。

### 5. エクスポート & プロジェクト管理
- **フォントファイル出力**: TrueType（`.ttf`）およびOpenType（`.otf`）形式。
- **iOS/iPadOS構成プロファイル**: `.mobileconfig` 形式での出力に対応。
- **プロジェクト保存**: `.fontproj.json` 形式でのローカル保存および読み込み。

## キーボードショートカット

（※アプリ内で `?` キーを押すことで画面上にも一覧が表示されます）

### ツール切替
| キー | 機能 |
| :--- | :--- |
| <kbd>B</kbd> | 筆・ブラシツール |
| <kbd>P</kbd> | ベクターペンツール |
| <kbd>V</kbd> | 選択・移動ツール |
| <kbd>A</kbd> | ノード編集・ダイレクト選択ツール |

| <kbd>H</kbd> | 手のひらツール（キャンバス移動） |

### 描画・ブラシ調整
| キー | 機能 |
| :--- | :--- |
| <kbd>[</kbd> / <kbd>]</kbd> | ブラシ・消しゴムサイズ変更 (-2px / +2px) |

| <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>A</kbd> | 全パス選択 |
| <kbd>Alt</kbd> + <kbd>S</kbd> | パスの単純化 |
| <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd> | 自動字幅・余白バランス調整 |

### 表示・キャンバス操作
| キー | 機能 |
| :--- | :--- |
| <kbd>Space</kbd> + ドラッグ | 手のひらツール（パン移動） |

## 開発・ビルド環境

### 前提条件
- Node.js 18.0 以上
- npm 9.0 以上

### インストールと起動

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (ポート 3000)
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

### ビルド

```bash
# 静的アセットのビルド (dist/ ディレクトリに出力)
npm run build
```

## プロジェクト構成

```text
src/
├── components/          # UIコンポーネント
│   ├── canvas/          # キャンバス構成レイヤー (背景, ガイド, 隣接文字, ルーラー等)
│   ├── GlyphCanvas.tsx  # メイン作図キャンバス

├── data/

└── App.tsx              # ルートコンポーネント
```
